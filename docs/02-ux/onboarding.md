# Onboarding

**Status: FROZEN direction** (концептуально проверен; детали экранов уточняются в low-fi, но направление не пересматривается)

## Flow

```text
O01 Зачем Pet AI
→ O02 Кто ваш питомец
→ O03 Расскажите о питомце
→ O04 Вот что я понял
→ Save Pet
→ Home
```

## Правила

- **Не добавлять длинную анкету.** После базового создания питомца enrichment — optional/progressive.
- На O03 пользователь рассказывает о питомце **обычным языком или голосом**.
- AI извлекает данные и **показывает их пользователю до сохранения** (O04).
- Спорные утверждения не становятся установленными фактами.

### Пример обработки неопределённости

Пользователь: «Была реакция на курицу».

Правильно:

```text
Возможная реакция на курицу
Источник: владелец (OWNER)
Статус: требует уточнения (UNCERTAIN)
```

Неправильно:

```text
Аллергия на курицу
```

## Связь с Pet Core

- O02 → Profile (минимальный набор).
- O03/O04 → начальная Memory с provenance (source=OWNER, status по уверенности).
- Сохранение → первое событие Timeline (создание питомца) — значимое событие.
