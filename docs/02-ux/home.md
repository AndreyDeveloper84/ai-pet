# Home

**Status: REVIEW**

## Назначение

Home — **state-driven screen**, а не dashboard из виджетов. Отвечает на три вопроса:

1. Что происходит сейчас?
2. Нужно ли владельцу что-то сделать?
3. Как быстро обратиться к Pet AI?

## Принцип честности состояния

Не утверждать «Всё хорошо» только потому, что система не знает о проблемах.

Предпочтительно:

> «На сегодня нет активных задач»

или другая семантически честная формулировка.

## Состояния

```text
NORMAL             — нет активных требований
ACTION_REQUIRED    — требуется действие владельца
UPCOMING_BOOKING   — предстоящая запись
ACTIVE_CARE        — активный план/рекомендация Care
MULTI_PET          — несколько питомцев (переключение active_pet)
```

## Приоритеты элементов

```text
P0 Critical        — критично (например, red flag сценарий)
P1 Action now      — действие требуется сейчас
P2 Upcoming        — предстоящее (запись, плановое)
P3 Observation     — наблюдение (например, AI_OBSERVATION о весе)
P4 Optional        — опциональное
```

## Правила

- Не захламлять Home всеми известными данными.
- Быстрый доступ к Pet AI — обязателен в любом состоянии.
- Содержимое определяется Current State + Care, а не полнотой данных профиля.
