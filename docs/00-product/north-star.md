# North Star

**Status: DECIDED**

## North Star Metric — Completed Care Loop

```text
NEED
→ AI
→ ACTION
→ COMPLETED SERVICE / MEANINGFUL RESULT
→ RESULT CAPTURED
→ PET CONTEXT ENRICHED
```

Это основная единица создаваемой ценности продукта.

## Рабочая метрика

**Completed Care Loops / Active Pet**

## Почему не другие метрики

- **AI messages** — объём чата не равен пользе; не оптимизировать под него.
- **Bookings** — booking без результата, вернувшегося в Pet Context, не закрывает loop и не усиливает продукт.
- **MAU** — следствие, а не единица ценности.

## Supporting funnel

```text
pet_created

```

## Цель текущей стадии

> Доказать, что AI, знающий конкретного питомца, способен провести владельца через реальную потребность до завершённого Care Loop и использовать полученный результат в следующем взаимодействии.
