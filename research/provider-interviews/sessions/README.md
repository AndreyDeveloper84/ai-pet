## Протокол

1. Набор — только сообщениями из `../recruiting-messages-v1.md` (DRAFT, рассылка = owner action).
2. Согласие на запись разговора — отдельным вопросом до старта.
3. Формат: разговор, не анкета. Грумер 30–40 мин, клиника 40–50 мин (+10 мин с врачом отдельно, если возможно).
4. **Research current workflow. Do not sell the product.** Не упоминать Pet AI, AI-matching, прототипы, state machine — до тех пор, пока не собран current workflow. Не спорить, не защищать идею.
5. Проверку наших наборов (G04: имя/порода/возраст/вес/особенность) проводить ТОЛЬКО после открытого ответа респондента (guide, вопрос 5a).
6. Заметки — в файл сессии в течение суток после интервью, пока память свежая.
7. FACT / OBSERVATION / INTERPRETATION — не смешивать. Цитаты — дословно.

## Логистика

- Длительность слота: грумер — 45 мин с запасом, клиника — 60 мин с запасом.
- Канал: созвон (Telegram/Zoom) или встреча на рабочем месте provider (предпочтительно для наблюдения за инструментами).
- Перед сессией: открыть session-файл, проверить guide, подготовить блокнот для цитат.
- После сессии: заполнить все разделы session-файла; незаполненное пометить «не спросили» — не выдумывать.
- Данные участников: только Participant ID, роль, тип бизнеса. Имена, контакты, названия клиник в репозиторий не заносить (public repo).
